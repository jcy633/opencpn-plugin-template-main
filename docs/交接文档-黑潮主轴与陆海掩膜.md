## 1. 已完成的功能

### 1.1 黑潮主轴与左右边界提取

**算法**：Wang et al. (2026, *Scientific Data*) 的**流线约束最大流速法**
（streamline-constrained maximum velocity method）。

- 论文与官方 MATLAB 代码位于
  `E:\my paper\Wang2026_黑潮轴与边界三维日尺度数据集_...\官方代码_Kuroshio-axis-and-boundaries\`
- 实现：`src/ncdf_kuroshio.cpp` + `include/ncdf_kuroshio.h`（`KuroshioExtractor`）
- UI：设置 → 识别 → 「黑潮主轴」组（提取主轴 / 导出CSV / 显示主轴 / 显示左右边界）

**流程**（与论文 Methods 逐条对应）：

| 步骤 | 内容 | 论文对应 |
|---|---|---|
| 0 | 种子点：数据网格距 × 黑潮流廊道 × 海点 | "seed points … 1/12° spacing" |
| 1 | 双向流线积分（RK2 中点法，步长 = 1 网格距） | "integrating the instantaneous velocity field in both directions" |
| 2 | A–E 五段拼装：断面截取 + 盒约束 + 环流检测 + 打分选优 + 降级细分 | Table 1 / Fig.1 |
| 3 | 陆海约束高斯平滑（55 km） | "Gaussian filter of 55 km" |
| 4 | 流线约束最大流速校正（±140 km 垂断面，7 km 采样，取沿流投影极大） | "Axis extraction and post-processing" |
| 5 | 裁剪至 16 N – 130.38 E | 代码后处理 |
| 6 | 左右边界：法向 7 km 步进，流速降至轴上 30% 处 | "Boundary determination" |
| 7 | 边界后处理：110 km 平滑 + 纬度/经度单调性 + 左右侧校验 | 代码后处理 |

**断面坐标（论文 Table 1，逐字核对无误）**：11 条唯一断面，相邻段共用
（A2/B1、B2/C1、C2/D1、D2/E1）。见 `kSections[11]`。

**与官方 MATLAB 的差异（已修的官方 bug）**：
- `xy_segbei` 跨段残留（L139 在段循环外初始化，会拼进上一个失败段的坐标）
- `correct_axis_transect` 中 `V_proj_masked(mask<1)=0` 导致 argmax 落到陆地 → 改为置 `-inf`

**保留的官方实现细节**（论文未写但代码有，物理上更站得住）：
- 取「沿流投影」最大而非「流速模长」最大，防止横穿断面的强涡抢走轴线
- 边界搜索的方向一致性过滤（`dir_cos > 0`）排除黑潮逆流与再循环
- 兜底顺序：最远同向点 → 最远有效海洋点 → 轴点

### 1.2 高分辨率陆海掩膜（GSHHG）

**来源**：`GenericMappingTools/gshhg-gmt` release 2.3.7 的 `gshhs_h.b`（高精度档，岸线 0.2 km）
**论文原方案是 ETOPO 2022 (30")**，但本机 `*.ngdc.noaa.gov` 被 DNS 劫持（公共 DNS 也返回
Facebook IP）、THREDDS 被防火墙挡，无法下载；GSHHG 经 GitHub API → CDN 绕过取得，
且岸线精度（0.2 km）优于 ETOPO 30″（0.9 km）。

**成品文件**（`C:\Users\季曹阳\AppData\Local\opencpn\plugins\ncdf_pi\data\`）：

| 文件 | 尺寸 | 覆盖 | 格距 | 用途 |
|---|---|---|---|---|
| `etopo_15s_gshhg_landmask.bin` | 4.1 MB | 12–36 N / 112–136 E | 15″ (0.37 km) | 黑潮区精细层 |
| `etopo_30s_gshhg_landmask.bin` | 116.6 MB | 全球 | 30″ (0.9 km) | 全球粗层 |

**格式**（`.landmask.bin`，自包含，插件直接读，无需 GSHHG 源文件）：
```
char[8]   magic = "NCDFLM01"
int32[4]  hdr   = { nlat, nlon, 0, 0 }
double[4] geo   = { latFirst, latStep(signed), lonFirst, lonStep(signed) }
uint64    nwords
uint64[]  bits  (1 bit/格，1 = 陆)
```

**载入**：`ncdf_pi::Init` → `loadLandMaskFiles()`，实测 **62 ms**（两层）。
搜索顺序：`%LOCALAPPDATA%\opencpn\plugins\ncdf_pi\data` → `…\etopo` →
`%APPDATA%\opencpn\…` → `%PROGRAMDATA%\opencpn\…`，文件名需含 `etopo`，
含 `15s`/`30s` 者作精细层、含 `60s` 者作粗层。

**栅格化工具**：`D:\_kuro_probe\mk_gshhg_mask.c`
（GSHHG 二进制 → 扫描线填充 → `.landmask.bin`）。已用 10 个已知海陆点双向校验通过。

## 3. 关键经验（踩过的坑）

1. **GLSL 源码只能是 ASCII**（GLSL 1.20 §1.1）。着色器字符串里写中文注释会让
   NVIDIA 编译器解析错乱，报 `undefined variable`，整张颜色图不显示。
   已在 `compile_shader_gl` 加了非 ASCII → 空格的消毒兜底。
2. **C 源文件里的中文注释在 GBK 下会吞掉括号**，导致 `C1075: "{" 未找到匹配的`。
   需加 UTF-8 BOM 或用英文注释。
3. **`glTexImage2D` 的 `GL_UNPACK_ALIGNMENT` 默认 4**：`GL_LUMINANCE`（1 字节/格）
   且宽度非 4 倍数时，纹理会斜切成横向长条。必须 `glPixelStorei(GL_UNPACK_ALIGNMENT, 1)`。
4. **GSHHG 栅格化两个坑**：① level 5/6 是南极（冰架前缘/接地线）不是水；
   ② 多边形经度是 0..360 展开的，必须先沿路径解缠再扫描线，否则跨本初子午线的
   多边形会被填成覆盖半个地球。
5. **`_FillValue = NaNf` 会让缺测判定失效**（`x != NaN` 恒为真）。已改为
   「数据为 NaN 一律缺测；fill 非 NaN 时再比对相等」，并把 `resize` 换成 `assign`
   避免同尺寸时旧值残留。

## 4. 待办 / 未决

| # | 事项 | 说明 |
|---|---|---|
| 1 | **A–E 断面硬编码** | 仅适用 115–132 E / 15–32 N 黑潮区，换流系需重做 `kSegs`/`kSections` |
| 2 | **只提表层单层轴** | `readTimeStepData` 把 `depth_idx` 强制为 0；论文是 30 层逐层 |
| 3 | **只提当前时次** | 无逐日批量导出。可行方案：当前时刻 / 日平均 / 月平均（**平均的是速度场不是轴线**，窗口按当前时次的日/月取；文件 `_Storage=contiguous`，限定黑潮区后 I/O 约减 200 倍） |
| 4 | **数据分辨率下限** | 需能分辨 ±70 km 垂断面：1/12° 可用，1° 不可用 |
| 5 | **MATLAB `stream2(...,1)` 步长语义歧义** | 1 格距 vs 1 度。已按 1 格距实现（论文的 `min_loop_points=8`+`distance_threshold=0.15°` 只有细步长才自洽） |
| 6 | **文件不全覆盖流廊道** | 目前"拼出能拼的段并报 N/5"，用户已确认可接受 |

## 5. 已回退的改动（2026-10-27，用户判定「越改越错」）

以下改动在 `f8b3528` 之后做过但**已回退**，勿重复踩：

1. **`ForEachTile` 的 `if (q.u1 <= q.u0) continue;`**
   想解决旋转海图下陆地出现空洞（该判据本是给日期变更线回绕用的，旋转时会误跳分块）。
   改成 `if (repeat && q.u1 <= q.u0) continue;` 后效果变差。
2. **插值值钳制**（`u/v`、`physical` 夹回数据范围）
   想解决陆地附近的异常红色（空洞填充让系数不连续 → B 样条重建过冲）。
3. **`DrawLandLayers` 移到所有数据图层之后**
   想解决多图层时后一层数据盖掉前一层陆地。当前代码里它在 `RenderGridOverlay` 内
   （每数据层调一次）。
4. **`FillTextureGaps`（近邻插值填补空洞）** 与 **`landMode` 面板开关**
   状态以 `f8b3528` 为准，需重新确认。

**这些改动的动机仍然成立**（陆地被海洋覆盖、陆地附近异常红、多图层互相遮挡），
只是实现方式不对。后续应先**定位到具体是哪一次绘制覆盖的**（可用
`glFinish()` + 分层截图，或逐个关闭数据图层二分）再动手。

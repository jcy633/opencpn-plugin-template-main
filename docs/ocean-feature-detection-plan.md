# 海流特征识别 — 实现方案（定稿 v2）

> 适用工程：ncdf_pi（OpenCPN 插件，OpenGL 2.1 / Win32 / C++17）
> 数据源：符合 CF 规范的 nc4 文件（海流 U/V、海温、海盐、zos，按文件实际包含降级使用）
> v2 变更：海流异常移出本期；取消例行降采样；新增计算/内存纪律（§11）与需求补充清单（§12）

## 0. 目标与硬约束

识别 6 类海洋特征：**锋面、中尺度涡、大型强流轴（黑潮/湾流类）、汇聚/辐散区、流场剪切区、上升流**。
（海流异常依赖全文件时间序列均值作参照场，属多时间步设计，本期不做，列入后续可选。）

| # | 约束 |
|---|------|
| C1 | **只渲染特征对象**。无特征海域渲染输出为零，海图原样显示；不渲染连续场底图、不做遮罩。另设**"数据图层仅在特征内显示"模式**（§4.1）：开启后四类平铺颜色图、等值线、方向箭头、粒子等既有显示效果**只在面状特征（涡/辐聚辐散/剪切/上升流斑块）边界内部渲染**，特征外部完全跳过；线状特征（锋面/急流轴）不承载此类裁剪显示 |
| C2 | **计算按数据更新触发**，帧渲染零计算零分配。拖图/缩放/旋转不触发任何重算 |
| C3 | 算法采用**经典方法 + 多源融合校验**，不用深度学习 |
| C4 | 检测阈值一律用**数据域内百分位**（自适应），不用绝对阈值 |
| C5 | OpenGL 2.1：immediate mode GL，**禁用 vertex arrays**（项目曾因堆损坏放弃）；渲染出口恢复 GL 状态 |
| C6 | 数据类型缺失时**优雅降级**，与 `m_fileHasXxx` 点亮逻辑同构 |
| C7 | 全部设置持久化到配置 |
| C8 | 渲染数据传递走结构体，不走全局变量 |
| C9 | **堆安全纪律**（§11.2）：新增代码统一 std::vector RAII、缓冲预分配复用、单一平坦顶点 arena、禁渲染/提取循环内分配 |
| C10 | **每帧任务清单锁定**（§11.1）：帧内只允许投影变换 + GL 绘制；渲染入口 API 上只接收 const 对象集，物理上调不到计算函数 |

## 1. 总体架构

### 1.1 三层计算（仅在数据更新时执行一次）

```
第 1 层  computeDerivatives()        O(N) 单次遍历（瞬态）
         高斯预平滑 σ=1 格距 → Scharr 3×3 逐像素求 8 个偏导，现场组合后即弃

第 2 层  派生标量（瞬态，同一遍历直接产出）
         ζ, δ, s_n, s_s, OW, 2D Liutex Ω, NGM_ρ(T+S 融合)/NGM_T/NGM_S, |V|

第 3 层  特征对象提取（持久输出）
         FrontFeature / EddyFeature / JetFeature / ZoneFeature
         → m_featureSet（lat/lon 坐标 + 属性数值，自包含）
```

**派生场瞬态化**（v2 关键变更）：派生标量场不再常驻缓存——L1/L2 产出后立即被所有启用特征的 L3 消费，随后释放（仅保留平坦 scratch 缓冲的容量，跨时间步复用）。对象自包含渲染与悬停所需的全部属性，**渲染阶段对派生场零依赖**。灵敏度滑块因此改为触发完整 L1~L3 重算（10~15ms，100ms 防抖），换取识别期间以外的零常驻内存。

### 1.2 数据流

```
时间步数据就绪 (prepareAllGrids 之后)
   └─ FeatureEngine::computeAll()          ← 唯一重算入口（数据更新线程，无 GL 调用）
        ├─ L1+L2：瞬态派生标量（scratch 缓冲复用）
        └─ L3：按启用开关提取对象 → m_featureSet（move 语义写入）

每帧渲染 (DoRenderncdfOverlay，渲染线程)
   ├─ 正常模式：既有四类颜色图/等值线/箭头/粒子/图例（现状不变）+ FeatureRender::drawAll
   └─ 特征内显示模式：先把面状特征多边形写入**模板缓冲（stencil）**，
      再按现状绘制颜色图/等值线/箭头/粒子（模板测试只放行特征内部像素），
      最后清模板、绘制全部特征对象

鼠标移动事件（非帧驱动）
   └─ FeatureEngine::hitTest() → 对话框读数区显示属性
```

| 文件 | 内容 |
|------|------|
| `include/ncdf_feature.h` | 特征对象结构体、FeatureEngine（含 scratch 缓冲成员）声明 |
| `src/ncdf_feature.cpp` | 三层计算全部算法 |
| `include/ncdf_feature_render.h` | FeatureRender 声明 |

## 2. 通用基础设施

### 2.1 第 1 层：求导

- 3×3 高斯预平滑（σ=1 格距）+ **Scharr 3×3** 求导
- 经纬网格尺度校正：x 向乘 cos(lat)、除以实际格距，输出物理单位（/m）
- 陆地/无效格（`ncdf_NOTDEF`/NaN）→ 派生量输出 NaN，不参与统计与提取
- **检测范围（v2.1，针对全球大网格）**：特征提取在**处理区域**内全分辨率进行。处理区域三种来源：
  ① 预设档：中国周边（15~45°N/100~135°E，~15 万点）／**亚洲海域（~0~55°N/60~150°E，~78 万点，预算可承受：瞬态缓冲 ~22MB，识别全流程 50~80ms，仅数据更新时付）**／全球；
  ② 手输经纬度框（识别页输入 min/max 经纬度）；
  ③ **海图圈画**（拖框矩形或圈选自由形 → 返回经纬度范围；代码库已有 `Selection` 结构体 + `RenderSelectionRectangle` 可作拖框底子，鼠标事件走 `MouseEventHook`）。
  **范围校验（②③共用）**：文件实际经纬范围从元数据已知（`firstGridPointLat/Lon`~`lastGridPointLat/Lon`）；手输时先提示文件有效范围（"文件覆盖 x°S~x°N / x°~x°E"）再校验，越界自动裁剪并告知；圈画时自动取圈画范围 ∩ 文件范围的**重叠部分**（无重叠则提示"圈选范围与数据文件无重叠"并不处理）。处理范围 = 来源范围 ∩ 文件范围 ∩（可选 ROI）。
- **降采样临界值（v2.2，放宽）：处理区域格点数 N > 1600 万** 时才触发每维 1/2 降采样（N 变 1/4），仍超标连续折半至 N ≤ 1600 万。
  依据修正：32 位进程实际可用 ~1GB（此前按 40MB 预算过于保守）；派生场按波次提取、同时存活 ≤4 张（16B/点），1600 万点峰值 **~256MB**，在 1GB 预算内且为瞬态（用完即释放）。
  **防碎片措施**（本项目 32 位堆碎片历史教训）：大缓冲采用**行块分配**（`vector<float*>` 每行独立分配，同 `cachedBaseGrid` 既有模式）而非单块连续 `vector<float>`，避免 256MB 级连续块分配失败。
  耗时：识别全流程随 N 线性，880 万点（全分辨率）约 0.5~1s，仅数据更新/滑块防抖时付一次；滑块拖动时显示"计算中"光标。
  三档实测对照：中国周边 15 万（~10ms）＜亚洲海域 78 万（~50ms）＜**全球 1/12° 880 万（~0.5-1s，全分辨率，不触发降采样）**；只有 1/36° 及以上的超高分辨率文件（如 4320×3400 ≈ 1470 万仍不触发）逼近临界。降采样触发时 debug 日志声明精度边界（<4 输出格距的特征不保证）。百分位阈值在处理区域内统计
- 唯一半分辨率例外：FTLE（LCS 边界为 >50km 大尺度结构，不受影响）

### 2.2 第 2 层：派生量公式

| 派生量 | 公式 | 用途 |
|--------|------|------|
| 涡度 ζ | ∂v/∂x − ∂u/∂y | 涡极性 |
| 散度 δ | ∂u/∂x + ∂v/∂y | 辐聚/辐散 |
| 法向应变 s_n | ∂u/∂x − ∂v/∂y | OW |
| 剪切应变 s_s | ∂v/∂x + ∂u/∂y | 剪切区 |
| Okubo-Weiss W | s_n² + s_s² − ζ² | 旋转/应变分区 |
| 2D Liutex Ω | ∇V 复特征值虚部 `√(det(G) − (tr(G)/2)²)`，判别式<0（旋转主导）时取值否则 0 | 涡核确认 |
| 密度 σ_t | ρ₀(1 − α(T−T₀) + β(S−S₀))，α≈1.7e−4 /K，β≈7.6e−4 /PSU | 密度锋 |
| NGM_f | \|∇f\| 归一化（Belkin & O'Reilly 2009） | 锋面强度 |
| 速度模 \|V\| | √(u²+v²) | 强流轴 |

百分位统计用 **256-bin 直方图 O(N)** 近似（0.4% 分位精度），避免排序。

### 2.3 特征对象模型（自包含；顶点存于单一平坦 arena，见 §11.2）

```cpp
struct FeatureSet {
    // 单一平坦顶点池：std::vector<float> xy (lon,lat 成对)；各对象持有 [offset, count)
    std::vector<float> vertexArena;

    std::vector<EddyFeature>   eddies;   // {contourVrange, center, radius_m, amplitude_m,
```

## 3. 特征算法

### 3.1 锋面（P1）— NGM + 双峰确认，**只显示密度锋**

> 决策依据：国际上卫星海洋学最常观测的是 SST 锋，但其中绝大多数本质上就是密度锋（中纬度温度主导密度）；盐度锋（如长江冲淡水羽流锋）同样制造密度梯度，也被密度锋捕获。密度探测唯一漏掉的是温盐补偿的"spiciness"梯度——这类无剪切、无环流动力学意义，不值得显示。因此**只画密度锋**是科学上成立的取舍，不只是简化。
> T/S 单源 NGM 仅作降级路径（缺 S 只有 NGM_T、缺 T 只有 NGM_S，C6）。

1. σ_t 场算 NGM_ρ（T+S 线性状态方程融合）
2. Cayula-Cornillon 确认（稳健简化版）：25×25 格滑窗直方图（20 bin），Otsu 类间方差比 > 0.85 判双峰；仅双峰窗口内 NGM 高值像元进锋线——压开阔洋渐变误报
3. 8 连通追踪成折线（带 visited 掩膜 + 最大长度保险，防死循环），迭代式 Douglas-Peucker 简化（容差 1 格距，显式栈不用递归）
4. 强度 = 段内 NGM 均值百分位；显示仅密度锋一类（降级时标"温度锋/盐锋"）
5. 融合点：T 锋被 S 补偿时 σ_t 无锋 → 不输出（物理上非动力锋面）

### 3.2 汇聚/辐散区（P1）

δ 符号分离 + 百分位阈值 → marching squares 闭合多边形 → 面积过滤 → 强度 = 区内 |δ| 均值百分位。与 NGM 高值共位的辐聚斑块 strength ×1.2。

### 3.3 流场剪切区（P1）

|s_s| 阈值斑块（同 3.2 流程）；附带输出总形变率 √(s_n²+s_s²) 的 P85 斑块为"强剪切/形变带"。

### 3.4 中尺度涡（P2）— 闭合等值线 + Liutex 确认 + T/S 定性

1. zos 滑窗极值（窗宽 ≈ 2× 参考变形半径）为候选
2. 闭合等值线增长（py-eddy-tracker 范式）：自极值以步长 = 场标准差/20 逐级 marching squares 外扩；等值线开口或与他候选合并即停
3. 接受：振幅 > 3~5 cm；半径 ∈ [0.5, 3]× 局地罗斯贝变形半径（纬度查表，缺表回退 30~50 km）；等高线级数 ≥ 2
4. Liutex 融合确认：核区 Ω 均值过阈且 ζ 符号一致 → confidence 高；核区无旋转 → 弃或标"低置信"（拒 SSH 无旋转假涡）
5. 定性：核 T/S 相对 2×半径环带均值的异常 → 冷涡/暖涡/盐核涡
6. 无 zos：退化为 Liutex+OW 连通域检测（低置信）

### 3.5 大型强流轴（P3）— 速度脊线 + 流向一致性

1. |V| 脊线：梯度垂直向扫描极大值像元 → 二次曲面亚像元拟合
2. 串接成轴线；约束：长 > 200 km、轴均速 > 0.4 m/s、相邻流向夹角 < 30°
3. 宽度 = 轴法向半高全宽；迭代 Douglas-Peucker 简化
4. 融合佐证：轴两侧 100 km 内 NGM_ρ 共位（黑潮陆侧锋）→ strength 加权
5. 命名靠地理位置先验，v1 输出"强急流轴"对象

### 3.6 LCS/FTLE 边界（P3，独立开关，最贵）

1. 反向时间 FTLE：**半分辨率**，T = 2 天，RK2 ~25 步，双线性插值（复用 `getInterpolatedUVFloat` 内核）
2. 流映射 Jacobian 中心差分 → Cauchy-Green 最大特征值 → σ = ln(λ_max)/|T|
3. 梯度方向非极大抑制 → 边界折线（输运屏障）
4. ~100 ms，仅开关开启时随数据更新计算一次

### 3.7 上升流（P4）— 四准则模糊评分

| 准则 | 隶属度 | 数据依赖 |
|------|--------|---------|
| A 冷异常 | T 相对 200km 滑动均值负异常（sigmoid） | 海温 |
| B 表层辐散 | δ>0 百分位隶属 | 海流 |
| C 水位趋势 | ∂zos/∂t < 0（**仅缓存上一时间步 zos 一张网格**，切时间步即弃；不是多时间步序列设计） | zos |
| D 近岸约束 | 到陆地格（数据无效格 = 免费陆地掩膜）的距离变换 < 100km（2-pass chamfer O(N)） | 任意掩膜 |

输出沿岸斑块 + `index∈[0,1]`（"上升流有利指数"，不做二值判定）。缺项权重重分配（单时间步无 C 等）。

## 4. 可视化规范（C1：只画对象）

### 4.1 总原则

- **"数据图层仅在特征内显示"模式**（顶层开关，持久化）：既有显示效果（当前选中数据类型的平铺颜色图、等值线、方向箭头、粒子）**只在面状特征内部渲染**，特征外部一个像素不画、海图原样。
  - 裁剪容器 = 当前启用的面状特征足迹并集（中尺度涡闭合轮廓、辐聚/辐散斑块、剪切区斑块、上升流斑块）
  - 线状特征（锋面折线、急流轴色带）**不承载裁剪显示**（无内部区域），自身照常以对象形式绘制
  - 实现：**模板缓冲裁剪**（GL 2.1 stencil，三步：写模板→带模板测试绘制数据图层→清模板）——零着色器改动、零纹理拷贝，代价可忽略。运行时检测 GL_STENCIL_BITS，无模板则降级为"完全隐藏数据图层"（v1 旧行为）
  - 颜色图例角标默认保留（否则裁剪后的颜色无法解读；精确量值另有悬停读数），提供子开关可隐藏
  - 关闭该模式时行为与现状完全一致
- 矢量对象层，immediate mode GL + GL_LINE_SMOOTH/抗锯齿
- 强度 → 线宽(1~4px)/透明度/色温三视觉变量；填充透明度 ≤ 30%
- 不在图上堆文字标签；属性走对话框读数区
- 防堆叠：每类只画强度前 N（默认涡 15、锋段 30、斑块 20）
- 渲染顺序在现有底图之后；出口恢复 GL 状态

### 4.2 逐特征绘制

| 特征 | 绘制 |
|------|------|
| 锋面 | 变宽变色折线（弱=淡黄→强=橙红）；仅密度锋（降级时温/盐锋同式绘制并标注） |
| 中尺度涡 | 半透明色盘（冷涡青蓝/暖涡橙红 20%）+ 真实闭合轮廓 + 中心十字 + 旋转弧箭头 |
| 强流轴 | 8~15px 半透明"急流色带"（Turbo 流速色）+ 人字纹流向；LCS 细亮白虚线 |
| 辐聚/辐散 | 斑块多边形（辐聚暖橙 25%、辐散青蓝 25%，0 区不画） |
| 剪切区 | 斑块多边形（橙黄系 20~30%），透明度绑强度 |
| 上升流 | 沿岸斑块青蓝半透明 + 向上小箭头，深浅绑指数 |

### 4.3 交互（两级 + 特征锚点图标）

- **锚点图标**（每个特征对象一枚，兼作点击热区与类型标识）：涡 = ⊕ 置于涡心；锋面 = ≋ 置于线段中点；强流轴 = ➤ 置于轴线中点（顺流向）；辐聚/辐散/剪切/上升流斑块 = ◆/▲ 置于质心。图标约 12px，只挂接在防堆叠后存活的对象上（数量有界）
- **图标防堆叠（可选项，留待末期按实际效果决定，见 §13）**：v1 图标在特征可见时直接显示，**不做任何显隐处理**——特征经防堆叠上限约束后本就稀疏时，此机制无意义。若实测密集再启用既有设计：
  ① **稀疏区不做任何分级**——图标间距充足时全部常显，强度不参与显隐；
  ② 仅在图标发生屏幕重叠（<20px）时仲裁：**强者保留、弱者隐藏**，弱者记录显现档位——把预测显现比例尺（"放大到预计不再重叠"）**向上取整到预设比例尺阶梯**（几何级数 ~8 档，档距 1.4×）；
  ③ **显隐只在跨档时批量更新**：比例尺阶梯每跨过一档（复用 `DoRenderncdfOverlay` 中已有的 `view_scale_ppm != m_last_vp_scale` 检测点，不新增任何比较），一次性刷新各图标 `visible` 标志（≤85 次赋值）；**帧渲染路径零比较零判断**，绘制时只读布尔标志。代价：图标显现最多比理论预测晚一档（约 40% 缩放），方向保守（只会晚现不会错现）。重叠检测也并入跨档触发（一次 O(n²) ≤85 图标扫描），普通小幅缩放/拖动零开销。特征本体（折线/色盘/斑块）不受影响始终绘制
- **悬停读数（保底，一定做）**：鼠标滑过特征本体或其图标 → 对话框"识别"读数区显示**速览指标**（见 §4.4 加粗项）
- **点击图标弹出指标面板（增强项）**：点击锚点图标 → 弹出属性小框（或对话框展开区）显示该特征**完整量化指标面板**（§4.4 全部项）。点击实现走 api-19 的 `WANTS_MOUSE_EVENTS` / `MouseEventHook` 鼠标回调（实施时核对确切签名）；不可用时降级为悬停速览（不阻塞）

## 11. 计算与内存纪律（v2 新增，实现时逐条对照）

### 11.1 每帧任务清单（C10，白名单之外一律禁止）

帧渲染路径（含拖图每帧重绘）只允许：

1. 缓存对象顶点的投影变换（~10³ 顶点，纯浮点运算）
2. immediate mode GL 绘制调用（折线/多边形/箭头）

**禁止出现在帧路径**：任何有限差分/统计/百分位、任何 malloc/new/push_back 扩容、任何文件 IO、任何日志格式化（高频日志仅限 debug 开关下的前 N 帧）、**任何比较/分支类显隐判断**（图标显隐的 `visible` 标志在跨比例尺档时批量写好，帧内只读布尔值）。API 强制手段：`FeatureRender::drawAll(const FeatureSet&)` 只接收 const 引用，渲染文件不 include 计算头文件，编译层面调不到计算函数。hitTest 只挂鼠标移动事件，不挂渲染回调；图标重叠检测与显隐刷新只挂在既有 `m_last_vp_scale` 变化检测点的跨档分支里。

### 11.2 堆安全纪律（C9，本项目历史教训：vertex arrays 堆损坏、copyFrom 深拷贝 double-free、vector 反复伸缩致 32 位堆碎片）

1. 新增代码**统一 std::vector / unique_ptr RAII**，禁止裸 new/delete/calloc-free 混用（现有代码的 calloc 约定不扩散到新模块）
2. 所有工作缓冲**按文件预分配一次、跨时间步复用容量**（`ensureGridAllocated` 模式）：时间步切换只 `clear()` + 写入，绝不 `shrink_to_fit`；对象容器同理
3. 特征顶点用**单一平坦 arena**（`std::vector<float>` + 各对象 offset/count），避免每条锋线一个小 vector 的海量小块分配
4. 提取/渲染循环内**零分配**——marching squares、连通域追踪的中间缓冲全部来自预留的成员 scratch
5. GL 只用 immediate mode（glBegin/glEnd），**禁用 vertex arrays/VBO**（项目既定教训）
6. `m_featureSet` 只用 move/swap 传递，禁拷贝构造（呼应 copyFrom 教训）
7. 计算模块无任何 GL 调用（呼应"GL 必须在渲染线程"教训）；纹理相关仍走既有管线
8. Douglas-Peucker 用显式栈迭代实现（防深递归爆栈）

## 3. 本轮修掉的三个 bug

### 3.1 三个标量层没有空白填补

**现象**：只有海流图层有空白填补，海温/海盐/海高没有。

**根因**：`CurrentOverlay` 有 `physicalTexID`/`hasPhysicalTex` 字段，三个标量层**没有**；
`RenderScalarColorMap` 调 `RenderGridOverlay` 时这两个参数走默认值 `NULL` →
`BuildPhysicalTex` 不建纹理 → 补空白的 `if (physicalTexID && …)` 不成立。

**修法**：三个标量层补上字段并透传。这正是「三份复制粘贴」的代价——同一 bug 要修三遍、漏一遍就出问题，
也是后来合并成 `ScalarOverlayBase` 的直接动因。

### 3.2 日期变更线接缝空白

**现象**：日期变更线附近有一条空白条带，「差一格」。

**根因**：陆地图层按 **nc 数据范围**建，而 1/12° 全球数据最后一格是 179.9167，差一格到 180。
数据纹理靠 `GL_REPEAT` 补上了这一格，陆地图层没有 → 露空白。

**修法**：全世界数据（`repeat`）时陆地图层按整周期建到 ±180；`ComputeLandUVs` 的经度改
**沿 x 逐点解缠**（原先按图层中心一次性 ±360，在日期变更线会让 UV 从 1.0 断到 0.0）。

### 3.3 `clear()` 不释放内存 → `bad allocation`

**现象**：颜色图加载不出来。日志里四类系数全部 `FAILED: bad allocation`。

**根因**：`myMessage.ucurr.clear()` 等只清元素、**不归还容量**，336 MB 一直占着地址空间；
叠加 4 路并行算系数的瞬时缓冲，撞到 **Win32 的 2 GB 上限**。

**修法**：`std::vector<double>().swap(v)` 真正归还容量。顺带发现 `zos` 压根没被 clear（一直漏的）。

## 4. 踩过的坑（按时间序，均已写入 CLAUDE.md）

1. **着色器字符串里的中文注释会被 GBK 吞字符** → GLSL 编译失败 → 整屏白屏。
   MSVC 按代码页 936 读源码，UTF-8 中文的尾字节会把后面的 `\` 并成双字节字符，毁掉 `\n` 转义。
   `compile_shader_gl` 的运行时消毒救不了（破坏发生在 C 编译期）。**着色器字符串里只能写 ASCII 注释。**

2. **泛洪/最近邻传播必须每趟用源标记快照**。一趟内原地改写 `src`，值会沿扫描方向拉成长横线。
   判据：日志里 `2 passes max` 却填了 250 万格。`FillTextureGaps` 长期「实现不成功」就是这个原因。

3. **掩膜查询必须绕道经纬度**。用 dataUV 的仿射查掩膜，在日期变更线会出现硬竖边（dataTex 是
   `GL_REPEAT`，仿射对 u 不是周期的）。

4. **`static std::mutex` 会导致插件加载期挂死**。非平凡类型的函数内 static 走 MSVC 的
   线程安全初始化（guard+TLS），而 `ncdfLog` 在插件加载期就被调用，那套机制尚未就绪。
   用 `static volatile LONG` + `InterlockedCompareExchange` 自旋锁即正常。

5. **自旋锁的提前 return 必须释放锁**，否则永久死锁。

6. **`glDrawArrays` 是异步的**，CPU 侧计时测不到 GPU 开销（渲染分段里 sea/fill/land 显示
   0.00 ms 不代表没花时间）。定位渲染卡顿要用「关掉绘制对比」这类办法。

7. **改 C 字符串里的 `\n` 转义不要用 Python 脚本**，shell/Python 会折叠成真实换行把字面量截断，
   编译报 `C2001`。直接用编辑器。本轮踩了 4 次。

8. **`s_landBuilt` 这类「只建一次」的 static 必须有失效入口**。原先永不复位，换文件后陆地图层
   停在第一个文件的范围，范围外没有 GSHHG → 补空白把海底色铺到陆地上。现象是「陆地颜色消失」
   **时好时坏，取决于哪个文件先加载**——这也是排查时最大的干扰源。

## 5. 诊断工具

### 5.1 运行时开关：`C:\ProgramData\opencpn\ncdf_flags.txt`

```
sea=1      海色 pass
land=1     GSHHG 陆地层
fill=1     补空白 pass
tileX=0    强制横向分块数（0=自动）
tileY=0    强制纵向分块数
dbgFill=0  把补空白区域涂成纯红
dbgTiles=0 分块统计常态输出（默认只在分块被误剔时记）
```

- 按**文件修改时间**判断是否重读，500 ms 内连 stat 都不做
- 改完存盘后**动一下地图**才会生效（渲染时才重读）
- **用法**：二分定位渲染问题。把 `sea/land/fill` 全置 0 就是「插件不画任何东西」，
  用来判断卡顿是否来自本插件

### 5.2 日志：`C:\ProgramData\opencpn\ncdf_debug.log`

| 前缀 | 内容 |
|---|---|
| `[perf]` | 各阶段耗时（`BuildLandLayer` / `texture build` 分段 / `prepareAllGrids` / `prepareCoeff` / `render`） |
| `[mem:tag]` | 内存：`myMessage/grids/coeff/total/peak` |
| `[landlayer]` | 陆地图层构建 + `selfcheck` |
| `[physfill]` | 最近邻传播格数 |
| `[tiles]` | 分块统计（`skipU1<=U0` 非 0 说明有分块被误剔） |
| `[phase2->3]` | 系数计算（出现 `FAILED` 就是出问题） |

**注意 `ncdf_debug.log` 会无限增长**（曾经 154 MB）。逐帧日志已删，但长时间运行仍建议定期清空。
